# 결과 설명과 검증 범위

## 사용자가 더 쉽게 끝내는 일

기업 목록을 직접 뒤져 후보를 옮겨 적고, 조건이 다른 견적을 계산기로 맞추고, 다시 문의 문장을 작성하던 과정을 하나의 화면 흐름으로 연결했다. 신규 창업자는 후보 탐색부터, 기존 사업자는 기존 견적을 기준으로 비교부터 시작할 수 있다. 생산품 검색은 공급 가능성의 확인을 대신하지 않는다.

## 구현한 Agent와 재현 원리

`run_agent`는 제한된 검색 도구만 자율 호출한다. 사용자의 지역·업종 필터는 도구 호출 과정에서 고정한다. 최대 두 번 검색한 뒤 조회 결과에 포함된 ID만 선택할 수 있다. 존재하지 않는 업체를 반환하면 오류 처리한다. AI의 자유 서술을 가격·신용·공급 가능성의 근거로 사용하지 않는다. 수행 기록에는 도구명과 결과 ID가 표시된다. 키 미설정 모드에서는 이 작업을 AI가 수행했다고 표시하지 않는다.

견적 추출은 미확인 값을 null로 유지하는 초안이다. 사용자 확정 이후에도 단가·세금·배송비·추가 비용이 확인되어야 총액을 계산한다. Decimal로 계산하며 총액은 소수 셋째 자리에서 반올림해 둘째 자리까지 표시한다. 기준 대비 차액은 동등한 품목·규격·수량·단위·통화일 때만 계산한다. 최소주문 미달·견적 만료·미래 발행일도 판정한다. 납기·최소주문·유효기간이 없으면 별도 확인 항목으로 남는다. 업체별 다른 반올림·결제수수료·할인 조건은 명시적으로 입력된 범위만 계산한다.

CSV·HTML 보고서에 입력값·출처·제한을 남긴다. HTML은 입력을 이스케이프하고 CSV는 수식 주입을 막는다. 사용자 확인 견적이 사실이라는 외부 인증은 제공하지 않는다. 원본 파일 해시와 소스 코드·동일 입력으로 계산 결과를 재현할 수 있으며 LLM의 후보 선택은 모델·공급자 변경에 따라 달라질 수 있다.

## 검증의 구분

- 자동 검증: 합성 기업 자료, 반입 원자성, 필수값·형식, 조건 필터, 모의 LLM 도구 호출과 전송 차단, 모의 국세청 응답·캐시, Decimal 계산, 관심 중복·기간, 다운로드 안전성, 키 없는 화면 흐름.
- 실제 런타임: 로컬 Streamlit 서버의 시작·화면 전환·검색 흐름을 agent API로 확인한다. 최신 실행 결과는 [진행 기록](PROGRESS.md)에 적는다.
- 미검증: 실제 기업 관측 원본, 원본 이용 허가·외부 전송 허가, 유료 LLM API 실호출, 실제 국세청 키, 선택 임베딩 모델, 센터 최소 사양 PC 성능, 도민 사용성 실험.

가상 데모 데이터와 모의 API 테스트 통과를 실제 필수 데이터 활용이나 외부 API 정상 작동으로 표현하지 않는다. 대회 제출 전 승인된 실제 기업 데이터로 동일 시나리오를 실행하고 행 수·누락률·검색 사례·실행시간을 추가 기록해야 한다.
