# 거래잇수다 제품 기획

제품 목표와 합의 범위다. 현재 구현 상태는 [HANDOFF.md](HANDOFF.md), 남은 구현·실검증은 [TODO.md](TODO.md)를 따른다. 기획의 목표를 이미 검증한 기능으로 읽지 않는다.

## 목표와 대상

제주 도민이 거래처별로 반복하는 검색·조건 확인·견적 정리·비교·문의 준비를 쉽게 한다. 신규 창업자와 기존 거래처가 있는 소상공인·기업 담당자 모두 지원한다.

신규 이용자는 제품/서비스·규격·수량·지역·납기를 입력한다. 기존 이용자는 기준 업체와 현재 견적을 추가한다. 기존 업체가 기업 DB에 없어도 사용자 입력으로 비교한다. 이름만으로 가격·납기를 추정하지 않는다.

현재 검색 화면은 품목 문장·지역·업종을 받고 규격·수량·납기는 견적/문의 단계에서 입력한다. 검색 단계의 조건 수집을 확장할지는 TODO에서 다룬다.

## 흐름

요구조건 입력 → 부족한 조건 질문 → 출처가 있는 기업 검색 → 후보 최대 5곳과 기존 업체 비교 → 같은 양식의 견적 문의 초안 → 견적 입력/수정 → 동일 조건의 총비용 비교와 보고서 저장.

견적 전에는 품목·업종·위치와 미확인 조건을 비교한다. 견적 후에는 규격·단위·수량·통화·세금 포함·배송·추가 비용을 확인해 비용을 계산한다. 미확인을 0원으로 바꾸지 않는다. 사용자는 유지·병행·전환을 검토할 수 있으며, 자동으로 계약·문의 발송·결제를 수행하지 않는다.

## Agent와 RAG

기업 하나를 검색 문서로 묶고 구조화된 지역/업종 필터와 키워드 검색을 수행한다. 선택적인 로컬 다국어 임베딩 연결은 있으나 실모델은 미검증이다. 현재 LLM은 검색 도구 호출·조회 ID 선택·확인 질문·견적 초안 추출을 맡고 숫자는 검증된 함수가 계산한다. 후보 근거는 원천 필드 일치로 표시한다. Agent가 확인 질문을 돌려주면 3단계에서 답을 적고 다시 찾을 수 있다(답은 질문과 짝지어 다음 검색 요청에 붙는다). 대화 전체를 모델에 이어 보내는 채팅은 아니다. 검색에 없는 기업·가격·연락처·공급 가능성을 생성하지 않는다. 자료 속 지시문은 명령으로 실행하지 않는다.

외부 전송 허용이 꺼져 있으면 모든 검색·추출 LLM 호출과 국세청 신규 조회를 차단한다. 공개 질의만 해석하는 별도 LLM 모드는 없다. 키가 없거나 전송이 꺼져 있으면 기본 검색·직접 견적 입력·계산·고정 양식 문의 초안을 제공하되 AI가 수행한 것처럼 표시하지 않는다. 국세청의 기존 로컬 캐시는 표시될 수 있다.

## 인기와 최신성

최근 30일간 기업 상세 열람과 비교 추가를 일자·임시 세션별로 중복 제거한다. 원문 검색어·견적은 인기 로그에 저장하지 않는다. 실사용 기록이 없으면 기록 수집 중이라고 표시한다. 인기는 품질·신뢰·최저가 인증이 아니다.

현재 원본 기준일, 사업자 상태의 마지막 성공 조회 시각, 견적 발행일·유효기간을 구분해 표시한다. 제품정보를 별도로 확인한 날짜를 저장·표시하는 기능은 없다. 관심 화면을 열면 키와 전송 허용 설정이 있는 경우 상위 최대 5곳의 국세청 상태를 캐시 주기에 따라 갱신한다. 실패 시 마지막 성공 시각을 새 시각으로 바꾸지 않는다. 품목·가격의 자동 최신화를 주장하지 않으며 앱이 꺼져 있으면 갱신하지 않는다.

## 제외 범위

디자인 확정·로그인·다중 서버·외부 자동 연락·결제·신용등급/부도 예측·현재 공급 능력 보증은 이번 기본 기능에 포함하지 않는다.
