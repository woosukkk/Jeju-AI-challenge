# 거래잇수다 실행·사용 매뉴얼

## 1. 설치와 실행

Windows 10/11, Python 3.11 권장. 첫 설치에는 인터넷과 패키지 다운로드가 필요하다. 순서는 `setup.bat` → (제주 상가 CSV를 `data_source\jeju_store.csv`에 두고) `import_data.bat` → `run.bat`이다. 브라우저에서 <http://localhost:8501>을 연다. 중지는 실행 창에서 Ctrl+C다. GPU는 사용하지 않는다. `.venv`는 제출 ZIP에 넣지 않고 평가 PC에서 설치한다.

직접 설치·검증:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env  # 최초 1회. 기존 .env가 있으면 덮어쓰지 않는다.
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address=127.0.0.1 --server.headless=true
```

`requirements-lock.txt`는 개발 PC에서 검증한 전체 설치 버전이다. 동일 환경이 필요하면 기본 requirements 대신 이 파일로 설치한다. 다른 OS/Python에서는 호환성 확인이 필요하다.

## 2. API 설정

`.env`를 편집한다. 키 값은 문서·Git·화면에 붙이지 않는다.

| 항목 | 설정 |
|---|---|
| LLM_PROVIDER | `openai`(평가·시연에 사용, 기본). `gemini`도 코드는 남아 있지만 무료 키가 연속 검색 5번 만에 429(호출 한도)에 걸려 평가에는 쓰지 않는다 |
| LLM_MODEL | 비워두면 공급자 기본값. 사용하는 계정에서 허용된 모델 ID로 변경 가능 |
| OPENAI_API_KEY | OpenAI를 선택한 경우의 키 |
| GEMINI_API_KEY | Gemini를 선택한 경우의 키 |
| NTS_API_KEY | 공공데이터포털 국세청 사업자등록정보 진위확인 및 상태조회 서비스의 일반 인증키(Decoding) |
| ALLOW_EXTERNAL_DATA | 기본 `false`. 자료의 외부 전송이 허용된 경우에만 `true` |
| AI_SESSION_LIMIT | 한 브라우저 세션이 쓸 수 있는 AI 작업 수(검색·문의 질문 업체 1곳·견적 추출·비교 해설을 각 1회). 기본 30, 0이면 AI를 쓰지 않음. 넘으면 키워드 검색·직접 입력으로 이어가고 위쪽에 'AI 한도 도달'이 보인다 |
| DATABASE_PATH | 기본 `data/trade_itsuda.sqlite3` |

LLM을 사용하면 입력 검색 조건, 조회된 후보의 업체명·생산품·업종·지역·기준일, 또는 견적 원문이 선택한 API에 전송된다. 사업자번호·키·원본 파일은 검색 LLM에 보내지 않는다. 국세청 조회에는 해당 업체 사업자번호가 전송된다. 이 설정은 허가를 대신하지 않는다. 개인정보·제한 자료를 제거하거나 가명처리하고 제공기관의 이용조건을 먼저 확인한다. 키가 없거나 외부 전송이 꺼져 있으면 기본 검색·수동 입력·계산·다운로드가 동작한다.

검색 1회당 LLM 요청 최대 6회, 도구 호출(업종 분류 확인·업체 검색·지역별 집계) 최대 5회, 후보 최대 5곳이다. 한도에 닿으면 도구 없이 지금까지의 결과로 마무리한다. 견적 추출·비교 해설은 1회, 문의 질문은 문의 대상 업체마다 1회 요청이다. 서버 일시 오류(500/503)만 2초 뒤 1회 다시 요청하고, 키·권한·한도 오류(401/403/429)는 다시 요청하지 않는다. 한 세션의 AI 작업 수는 `AI_SESSION_LIMIT`(기본 30)로 막는다. 전체 예산은 공급자 콘솔에서 따로 한도를 건다. 실호출은 Gemini `gemini-3.5-flash-lite`(2026-11-17)와 OpenAI `gpt-5.4-mini`(2026-11-18)로 확인했다([TODO P0-02](TODO.md)). 무료 Gemini 키는 연속 실행 때 429가 날 수 있다. OpenAI `gpt-5.4-mini` 기준 검색 1회 약 0.004달러, 6단계 한 번 약 0.01달러였다(2026-11-18 측정, [결과 설명](RESULTS.md)).

## 3. 먼저 데모로 확인

1. 데이터 관리 → **가상 데모 4곳 불러오기**. 빈 DB에서만 동작한다.
2. 거래처 찾기는 6단계로 진행한다. 각 단계는 **다음**으로 넘어가고 **이전**으로 돌아가도 입력값이 남는다.
   1. 필요 품목: 이용 목적에서 `기존 거래처와 비교` 선택, 품목 `라벨 스티커`, 기존 거래처 이름 입력.
   2. 지역: 시 → 읍·면·동 순서로 고른다(모르면 전체). 키가 있으면 AI Agent가 켜져 있다.
   3. 후보 고르기: 가상 한라라벨 → **비교에 담기**(최대 5곳).
   4. 문의 준비: 품목·규격·수량·단위·추가 요청을 한 번 적으면 기존 업체와 후보 모두의 문의 초안이 만들어진다.
   5. 견적 입력: 업체를 하나씩 골라 금액·조건을 넣고 저장한다. 4단계 조건이 미리 채워진다.
   6. 비교 결과: 기존 거래처 견적이 기준으로 선택된다. 보고서 HTML·CSV 다운로드, AI 비교 해설.

다음 테스트 견적은 실제 가격이 아니다. 기존 업체: 라벨 / 50mm / 1,000개 / 단가 100 / KRW / 세금 포함 / 배송비 0 / 추가 비용 0. 후보: 동일 조건에서 단가 90. 두 견적을 원문 확인 상태로 저장하면 총액은 각각 100,000.00과 90,000.00, 후보 차액은 -10,000.00이다. 배송비를 빈칸으로 두면 총액은 미확정이다. 규격·수량이 다르면 차액은 비교 불가다.

## 4. 실제 데이터 가져오기

데모와 실제 자료는 별도 DB로 사용한다. 데모를 이미 불러온 DB가 있으면 `.env`에서 `DATABASE_PATH`를 다른 파일(예: `data/jeju_store.sqlite3`)로 바꾸고 앱을 다시 실행한다. 원본·가공본·임베딩을 공개 저장소에 올리지 않는다.

가장 빠른 방법(평가 PC 권장): 제주데이터허브 「제주특별자치도 상가(상권) 정보」 CSV를 `data_source\jeju_store.csv`로 두고 `import_data.bat`을 실행한다. 출처명 `제주데이터허브 제주특별자치도 상가(상권) 정보`와 기준일 2025-09-18이 자동으로 들어가고, `.env`의 `DATABASE_PATH`에 저장된다. 다른 위치의 파일은 `import_data.bat "파일 경로"`로 넘긴다. 2026-11-17 새 폴더 설치에서 57,347곳 반입에 약 10초가 걸렸다. 결과·원본 SHA-256·제외 사유별 행 수가 창에 출력된다.

화면에서 가져올 때는 아래 절차를 따른다.

데이터 관리에서 CSV(UTF-8/CP949) 또는 XLSX 평면 테이블을 선택한다. 파일은 최대 20MB, XLSX 압축 해제 크기 최대 100MB, 최대 100,000행이다. 시트 이름 또는 0부터 시작하는 시트 번호를 지정한다. 필수 열은 아래와 같다.

| 정규화 열 | 인정하는 원천 열 예 |
|---|---|
| name | 기업명, ent_nm |
| industry | 업종명, ksic10_biz_nm |
| products | 주요생산품, main_products |
| region | 주소_읍면동, address_emd |
| source_date | 데이터 기준일, base_date |
| business_number (선택) | 사업자번호, biz_num |
| id (선택) | ked_code, kedcd |
| website (선택) | http/https 주소 |

제주데이터허브 「제주특별자치도 상가(상권) 정보」(https://jejudatahub.net/data/view/data/793) CSV는 그대로 가져올 수 있다. 상호명→업체명, 상권업종중분류명→업종, 상권업종소분류명·표준산업분류명→생산품, 시군구명·행정동명→지역으로 쓰고, 상호명·지역·지번주소·도로명주소로 업소를 구분한다. 파일에 기준일 열이 없으므로 공통 기준일에 허브의 수집일(2025-09-18)을 입력한다.

출처명은 화면에서 반드시 입력한다. 공통 기준일은 파일에 기준일이 없을 때만 입력하고 원자료 기준일을 적는다. 파일별 열은 [데이터 명세](DATA_USAGE.md)를 확인한다. 출처와 ID로 기업을 식별하며 출처명이 달라지면 별도 기업으로 들어온다. 필수값이 비거나 형식이 틀린 행, 완전히 같은 중복 행은 건너뛰고, 같은 업소의 다른 업종 행은 첫 행의 생산품에 합친다. 제외·병합한 행은 사유별 행 수와 원본 행 번호를 화면에 보여준다. 동일 기업을 더 오래된 자료로 덮어쓰는 작업은 전체 반입을 취소한다. 행을 제거했다고 기존 DB 기업이 삭제되지는 않는다. 입력 파일 SHA-256·행 수·반입 일시를 보관하지만 원본 파일 자체는 DB에 저장하지 않는다. 기준일·출처명은 제공 자료의 선언이며 외부 검증 결과는 아니다.

명세서 XLSX에는 실제 회사 목록이 없으므로 그대로 가져올 수 없다. 일부 기업의 생산품·지역·업종이 결측이면 별도 정제한 뒤 반입한다. 값을 추측해서 채우지 않는다.

## 5. 견적·조회 기록과 최신성

5단계 '사업자 상태 확인 (선택)'에 사업자번호를 넣으면 국세청에서 계속·휴업·폐업 여부를 한 번 조회해 6단계 비교 열에 함께 보여 준다(`NTS_API_KEY`와 외부 전송 허용 필요, 저장하지 않음). 상가 데이터에는 사업자번호가 없어 업체 정보에서 자동으로 조회하지는 않는다. 4단계 문의 초안은 오른쪽 위 복사 버튼으로 복사한다.

견적 원문은 자동 저장하지 않으며 사용자가 저장한 추출·입력값은 로컬 DB에 남는다. 사용 후 거래처 찾기 5단계(견적 입력)에서 업체를 골라 **이 업체 견적 삭제**로 지운다. DB는 로컬 단일 사용자용으로, 사용자별 계정 분리·암호화를 제공하지 않는다. 공용 PC에서 사용자별 보안이 필요하면 사용자를 위한 별도 OS 계정/별도 DB와 접근권한을 설정한다. `run.bat`은 다른 PC에서 접근할 수 없도록 localhost에만 바인딩한다.

최근 관심은 동일 세션·동일 날짜·동일 행동의 중복을 제거한다. 순위의 관심 수는 상세·비교 행동을 합쳐 세션·일별 1회다. 새 브라우저 세션이나 다음 날에는 다시 집계된다. 개인정보·원 검색어·견적 금액은 이벤트에 저장하지 않는다. 기록은 DB를 공유하는 이 PC의 이용 이력이며 제주 전체 검색량이 아니다. 35일을 넘은 기록은 관심 화면을 열 때 삭제한다.

국세청 성공 응답은 24시간 캐시, 실패 후 재요청은 5분 간격이다. 실패해도 이전 성공 시각을 최신으로 바꾸지 않는다. 관심 화면의 상위 최대 5곳과 수동 조회에서만 갱신하며 앱 종료 중에는 실행하지 않는다. 원본 기업 기준일·국세청 조회 성공 시각·견적 발행일/유효기간은 각각 다른 의미다. 현재 품목·가격·납기는 업체에 다시 확인해야 한다.

## 6. 선택 사항: 로컬 의미 검색

기본 검색에는 불필요하다. CPU 임베딩을 추가하려면 `requirements-semantic.txt`를 설치하고 `intfloat/multilingual-e5-small` 모델 파일을 공식 모델 저장소에서 내려받아 `models/e5`에 준비한다. 모델 다운로드·최초 인코딩 시간과 용량은 현장 사전 점검 대상이다. 앱은 임의 다운로드하지 않는다. 의미 검색 후보는 공급 가능 확정 추천이 아니며 수치 점수를 확률로 표시하지 않는다. 모델과 실제 최소 사양 PC의 처리 속도는 아직 검증하지 않았다.

## 7. 개발 검증과 문제 해결

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ty check
```

실제 데이터 검색 품질·시간 측정(외부 전송 없음): `.\.venv\Scripts\python.exe scripts\measure_search.py`. AI Agent까지 재려면 `--agent --pause 30`을 붙인다(키 필요, 요금 발생, 무료 키는 분당 호출 한도가 있어 쉬는 시간을 둔다). 결과는 `outputs/`에 저장된다.

제출 ZIP: 변경을 모두 커밋한 뒤 `.\.venv\Scripts\python.exe scripts\make_submission.py --data "제주특별자치도 상가(상권) 정보.csv"`. 커밋된 파일만 담고 `.env`·DB·`.venv`·모델·키 형태 문자열이 있으면 ZIP을 만들지 않는다. 결과는 `dist/trade-itsuda_<커밋>.zip`.

AI 응답이 `429 호출 한도·요금`이면 잠시 뒤 다시 시도한다. 무료 Gemini 키는 분당 호출 수가 적어, 2026-11-17 측정에서 검색 Agent를 연달아 5번(약 40초 동안 요청 십여 건) 실행하자 429가 났다. 이때 앱은 키워드 검색 결과로 이어간다. 평가용 키는 호출 한도가 넉넉한 키를 쓴다. API 오류: 키 자체를 공유하지 말고 공급자·모델 ID·사용량·포털 승인 상태를 확인한다. 키 변경 후 앱을 재시작한다. PDF 추출 불가: 스캔·암호 PDF는 지원하지 않는다. OCR 후 텍스트로 입력한다. 견적 여러 품목은 한 품목씩 나눠 입력한다. 포트 8501이 사용 중이면 기존 앱을 종료하거나 직접 `--server.port=8502`로 실행한다.
