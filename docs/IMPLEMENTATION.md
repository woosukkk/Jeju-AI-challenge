## 스택

Python 3.11, Streamlit, SQLite, pandas/NumPy, Pydantic, OpenAI SDK(Gemini 호환 API 포함), httpx, python-dotenv, openpyxl/pypdf, pytest. 선택적인 의미 검색은 sentence-transformers와 multilingual-e5-small을 CPU에서 사용한다. 금액은 Decimal로 계산한다. 기본 UI에서 제품 동작을 먼저 검증한다.

## 완료한 1차 기능 커밋

1. 기획·데이터 규칙·프로젝트 설정 문서
2. 검증 모델·설정·SQLite 저장소
3. 실제 파일 반입과 명시적인 합성 데모 데이터
4. 구조화 필터·키워드/선택적 의미 검색과 근거
5. 기존 업체·견적 저장과 동일 조건 비용 비교
6. Gemini/OpenAI 요구 해석·제한된 Agent·견적 추출
7. 국세청 상태조회·갱신·실패 처리
8. 중복 제거된 최근 인기 집계
9. 안전한 보고서·견적 문의 초안 내보내기
10. 신규/기존 Streamlit 화면·매뉴얼·실행 파일·통합 검증

위 목록은 코드 구현 완료 기록이며 실제 데이터·API·현장 검증 완료를 뜻하지 않는다. 이후에도 기능별 커밋과 새 커밋 10개마다 푸시 규칙을 적용한다. 커밋 수를 맞추기 위한 빈 커밋은 만들지 않는다. 다음 푸시 전 실제 ahead 수를 확인하고 푸시 후 원격 해시를 대조한다.

## 변경이 닿는 곳

문서, 환경설정, DB와 데이터 모델, 반입/검색/견적/외부 API/로그/내보내기, 화면 호출부, 합성 테스트와 설치·실행 매뉴얼을 함께 완성한다. 실제 원본·키·고객 견적은 저장소에서 제외한다. 반입은 파일 전체를 검증한 후 한 트랜잭션으로 반영하고 오류 시 기존 자료를 유지한다.

## 검증

데이터 반입의 누락/중복/오류 원자성, 검색 필터·근거·빈 결과, Decimal 금액·단위·수량·세금 기준·미확인 비용·만료, LLM 도구 인자와 호출 한도·외부 전송 차단, 국세청 오류와 캐시, 인기 기간/중복, HTML/CSV 내보내기와 기본 UI 흐름을 검증한다. 실제 키·데이터 없는 검증은 모의 검증이라고 기록한다.
